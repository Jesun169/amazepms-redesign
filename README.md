# AmazePMS - Premium Project Management Software

## Overview
A modern, premium, and highly interactive project management software landing page built with Next.js.

## Features
- Premium UI/UX Design
- Advanced Animations with GSAP & Framer Motion
- Smooth Scrolling with Lenis
- Particle Background Effects
- Glassmorphism Design Elements
- Fully Responsive
- Dark/Light Theme Support
- Interactive Sections
- Micro-interactions

## Tech Stack
- Next.js 14
- React 18
- Tailwind CSS
- GSAP
- Framer Motion
- Lenis
- React Icons
